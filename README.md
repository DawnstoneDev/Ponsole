# Ponsole

Ponsoleは、macOS向けに開発されたネイティブログビューアです。

macOS Tahoeを意識したインターフェースで、ログファイルを読み込み、検索・フィルター・ページングなどを利用してログを確認できます。

大量のログを扱うことも考慮し、必要な範囲をページ単位で読み込む構成を採用しています。

## ログの読み込み

Ponsoleは、システム上のログを自動的に検索・収集することはありません。

ユーザーが明示的に追加したログファイルのみを読み込みます。

ログを追加する方法は以下の2つです。

- Finderなどからログファイルをドラッグ＆ドロップ
- ファイル選択画面からログファイルを選択

これにより、意図しないログファイルを自動的に読み込むことなく、必要なログだけを確認できます。

## ログ表示

読み込んだログは、以下の情報を分離してテーブル形式で表示します。

- 時刻
- ログレベル
- デバイス名
- プロセス
- PID
- メッセージ

生のログテキストをそのまま表示するのではなく、解析できる情報をそれぞれの列に分けて表示することで、必要な情報を確認しやすくしています。

## Jamfログ対応

Jamfで使用される形式のログを解析できます。

例えば、以下のような形式のログを解析します。

```text
Wed Jul 30 21:17:01 DEVICE_NAME jamf[40648]: Error ...
````

この形式から、時刻・デバイス名・プロセス・PID・メッセージをそれぞれ抽出して表示します。

メッセージ欄には、プロセスやPIDなどの情報を含めず、ログのメッセージ部分を表示します。

## フィルター

サイドバーからログレベルを選択できます。

* すべて
* Error
* Warning
* Info
* Debug

フィルターは現在選択しているログに対して適用されます。

複数のログを読み込んでいる場合でも、それぞれのログを切り替えながら確認できます。

## 検索

検索欄からログの内容を検索できます。

検索とフィルターを組み合わせることで、大量のログの中から必要な情報を絞り込めます。

## 大容量ログへの対応

大きなログファイルをすべてメモリに保持する方式ではなく、必要な範囲をページ単位で読み込む方式を採用しています。

ログの表示処理と件数計算も分離し、件数の計算など時間のかかる処理はバックグラウンドで実行します。

これにより、大きなログファイルを扱う場合でも、UIの操作性をできるだけ維持できるようにしています。

## ページング

大量のログが存在する場合、すべての行を一度に画面へ表示するのではなく、ページ単位で表示します。

現在のページを移動しながら必要なログを確認できます。

## 対応ログ

Ponsoleは一般的なテキストベースのログを対象としています。

特に以下のようなログ形式を想定しています。

* macOS関連ログ
* アプリケーションログ
* Jamf関連ログ
* プロセスログ
* システム管理関連ログ
* その他のテキスト形式ログ

ログ形式によって解析できる情報は異なります。

├── LogLibrary.swift
└── LogTableView.swift

## 主要ファイル

### PonsoleApp.swift

アプリケーションのエントリーポイントです。

### ContentView.swift

アプリ全体のレイアウトと、サイドバー・ログ表示領域・ログ追加処理などを管理します。

### SidebarView.swift

読み込んだログとフィルターを表示するサイドバーを管理します。

### DropLogView.swift

ログがまだ読み込まれていない状態で表示される、ログ追加用の画面です。

### LogModel.swift

ログエントリ、ログファイル、ログレベル、フィルターなどのデータモデルを定義します。

### LogParser.swift

ログファイルの読み込み、解析、フィルター、検索、件数計算などを担当します。

### LogLibrary.swift

読み込んだログファイルの管理を担当します。

### LogTableView.swift

解析されたログをテーブル形式で表示し、ページングや読み込み状態などを管理します。

## 開発環境

PonsoleはXcodeを使用して開発できます。

プロジェクトをXcodeで開き、対象のMac向けにビルドして実行してください。

## 起動

Xcodeでプロジェクトを開き、Ponsoleをビルドして実行します。

アプリを起動した後、確認したいログファイルをドラッグ＆ドロップするか、ファイル選択から追加してください。

## 初回起動時

macOSのセキュリティ機能により、ダウンロードしたPonsoleを起動できない場合があります。

その場合はターミナルで以下を実行してください。

```bash
xattr -dr com.apple.quarantine /path/to/Ponsole
```
